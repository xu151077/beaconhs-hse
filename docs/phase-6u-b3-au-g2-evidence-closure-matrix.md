## 4. Deferred prerequisites (must not be skipped)

1. Browser multipart: real file > 256 MiB and upload-control surface with enough disk/memory. None available (only 100 MB cap for documents; 3.4 GiB VPS).
2. Freeze browser state: VM restricted, cannot use tenant cleanup for full UI without permanent test state capture; requires admin no-state verification.
3. Collabora: service not returning successful, configuration already documented issue; separate fix plus a real save sequence.
4. R2/IAM, lifecycle, backup/restore, alerting: explicit production authorization needed and account sources are not in-repo.

### 5. Recommendations

1. Reuse existing DB gates only; do not run more `pnpm test` from local host.
2. Treat G2 as **NOT PASS today** until at least production smoke/tunnel, R2/IAM, lifecycle, restore, alerts, multipart, freeze UI, and full Collabora sequence are evidenced.
3. Highest-value open work: production authorization and DR/ops tests; publish signed evidence with bucket lifecycle + one restore check.
4. A dedicated test subnet + large-storage staging tenant could close multipart and freeze browser tests without touching production.
